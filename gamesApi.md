# Create Games CRUD API. 

### Purpose
Create a APIs in server.js file to CRUD games in memory (No DBs currently)
The API should return the games UUID that is generated. 

### Tasks
1. Setup the express server in package.json. 
2. Create a single file `server.js` that will contain all the APIs.
3. Use the `games.js` file. Most of the logic should be handled in the file. Modify the games.js file if needed but keep the overall structure same.
